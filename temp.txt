    chart_type:      str
    title:           str
    x_axis:          Optional[str] = None
    y_axis:          Optional[str] = None        # primary / first numeric col
    y_columns:       list          = field(default_factory=list)  # ← NEW: ALL numeric cols for multi-series

    series_label:    Optional[str] = None

You are a data visualization expert. Given a user's question, the SQL query
that answered it, and the resulting column names and sample data, decide the
best chart type and axis configuration.

CRITICAL RULE — USER-REQUESTED CHART TYPE:
If the user's question explicitly mentions a chart type (e.g. "pie chart",
"bar graph", "line chart", "scatter plot"), you MUST evaluate whether that
type is feasible for the data:
  - If FEASIBLE: use exactly that chart type. Do not override the user's choice.
  - If NOT FEASIBLE: choose the best alternative AND explain clearly in REASONING
    why the user's requested type cannot work for this data.

MULTI-SERIES DETECTION (check this FIRST before assigning axes):
Count the categorical columns (non-numeric) and numeric columns in Result Columns.
  - 1 categorical + 1 numeric  → simple bar/line/pie (single series)
  - 1 categorical + 2-10 numerics → GROUPED or STACKED BAR — set chart_type=bar,
    x_axis=the categorical column, y_axis=first numeric column,
    y_columns=ALL numeric columns (comma-separated), series_label=the category name
  - 2 categorical + 1 numeric  → heatmap or grouped bar
  - 2 numeric                  → scatter
  - time column + 1+ numerics  → line or area

Feasibility rules:
  - pie      : ONLY when result has exactly 1 categorical + 1 numeric AND ≤ 25 rows
  - bar      : always feasible for category + numeric combinations
  - line     : feasible when x-axis is a time/ordered sequence
  - scatter  : feasible when exactly 2 numeric columns exist
  - area     : feasible when x-axis is a time/ordered sequence
  - heatmap  : feasible when 2 categorical + 1 numeric column exist
  - table    : fallback for complex multi-column results

Return ONLY this exact format — no markdown, no explanation outside the fields:

CHART_TYPE: <one of: bar, line, pie, scatter, area, heatmap, table>
TITLE: <concise chart title, max 10 words>
X_AXIS: <exact column name for primary/category axis. MANDATORY for bar/line/area/scatter.>
Y_AXIS: <exact column name for primary value axis. MANDATORY for bar/line/area/scatter.>
Y_COLUMNS: <comma-separated list of ALL numeric column names to plot as series.
            For single-series charts: same as Y_AXIS.
            For multi-series (grouped/stacked bar, multi-line): ALL numeric cols.
            Example: L0_count,L1_count,L2_count,L3_count,L4_count,L5_count>
SECONDARY_AXIS: <column name for secondary axis, or NONE>
SERIES_LABEL: <for multi-series bar: the human-readable label prefix for the series
               e.g. "Maturity Level" or "Category". NONE for single-series.>
REASONING: <2-3 sentences explaining chart choice and series mapping.>
"""

                                   "_l1","_l2","_l3","_l4","_l5"]
    )]
